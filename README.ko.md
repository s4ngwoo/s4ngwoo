# 👋 이상우 (s4ngwoo)

**AI와 비즈니스를 연결하는 개발자.** (대한민국 기반)

빠른 실행력과 투명한 프로세스를 바탕으로 실용적인 AI 툴을 만듭니다. B2B 솔루션에서 시작하여 B2C 및 SaaS 플랫폼으로 확장해 나가는 비전을 가지고 있습니다. 투자자, 클라이언트, 비즈니스 파트너와의 협업을 환영합니다.

## 💡 관심 분야

- **AI**: 로컬 LLM 배포, RAG, AI 에이전트
- **온톨로지(Ontology)**: 현실 문제 해결을 위한 구조화된 데이터 시스템 설계
- **자동화(Automation)**: 워크플로우 자동화, CLI 중심 툴 개발
- **Physical AI**: 디지털과 물리적 시스템의 연결
- **데이터(Data)**: SQL, 데이터 모델링, 지식 체계화
